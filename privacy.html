Política de privacidad de HeartTrack

Última actualización: 20 de octubre de 2026.

HeartTrack es una aplicación para registrar entrenamientos con un sensor Bluetooth de frecuencia cardíaca compatible. No requiere crear una cuenta y no incorpora publicidad, seguimiento ni herramientas de analítica de terceros.

Datos guardados en el dispositivo

La aplicación procesa las pulsaciones recibidas por Bluetooth, fechas y duración de las sesiones, estadísticas de entrenamiento y las preferencias que configuras. Las sesiones reales se guardan en el almacenamiento local de la app. El diagnóstico Bluetooth conserva un registro local limitado de eventos de conexión para ayudarte a investigar cortes de señal. HeartTrack no envía estos datos a servidores del desarrollador y no utiliza CloudKit para sincronizarlos. Las copias de seguridad del dispositivo, si están activadas, dependen de tus ajustes y de los servicios de Apple.

El modo Simulación utiliza datos temporales en memoria, separados de tus sesiones reales. Estos datos no se guardan en Salud.

Salud de Apple

La integración con Salud es opcional. Si concedes los permisos y eliges Guardar en Salud, HeartTrack guarda el entrenamiento y sus pulsaciones mediante HealthKit. Solo consulta los datos que la propia app ha guardado para evitar duplicados al reintentar. No lee datos de otras aplicaciones. Los datos de Salud no se utilizan para publicidad ni para crear perfiles comerciales. El almacenamiento y la sincronización de Salud se rigen también por tus ajustes y las condiciones de Apple.

Exportación de sesiones

Puedes generar un PDF o CSV de una sesión y compartirlo mediante la hoja de compartir del sistema. Tú eliges el destino. Los archivos compartidos quedan bajo tu control y el de la aplicación o persona que elijas; una vez exportados, no se borran al eliminar la sesión original en HeartTrack.

Permisos y control

Bluetooth permite conectarse a la banda. Las notificaciones son opcionales y se utilizan para avisos locales de entrenamiento. Puedes cambiar los permisos en Ajustes de iOS y en Salud. Puedes eliminar sesiones desde Histórico y limpiar los eventos desde Diagnóstico Bluetooth. Los datos locales se conservan hasta que los eliminas o desinstalas la app. Las copias ya guardadas en Salud se gestionan desde Salud y los archivos exportados desde sus destinos.

Contacto y cambios

Para consultas sobre el funcionamiento o la privacidad de HeartTrack, utiliza las incidencias del repositorio de soporte. No incluyas datos de salud ni información personal en una incidencia pública.

Esta política se actualizará si cambia el funcionamiento de la app. HeartTrack está orientada al ejercicio y al bienestar y no ofrece diagnósticos ni indicaciones de tratamiento médico.

Esta web de soporte

Esta web no añade publicidad, formularios de recogida de datos ni herramientas de analítica. Esta web se aloja en GitHub Pages. GitHub registra y conserva las direcciones IP de los visitantes por motivos de seguridad. Consulta la política de privacidad de GitHub para conocer el tratamiento de esos datos técnicos. Las incidencias de soporte se gestionan en GitHub y son públicas. Comparte solo la información técnica necesaria y no incluyas datos de salud, direcciones, teléfonos ni otros datos personales.

Privacy summary in English

HeartTrack has no account, advertising, tracking, third-party analytics or developer-operated backend. Heart-rate readings, workouts, preferences and a limited Bluetooth diagnostic log are processed and stored locally. The app does not use CloudKit synchronization. Device backups depend on your Apple settings.

With your explicit authorization and Save to Health action, the app writes workouts and heart rate to Apple Health. It only checks records previously created by HeartTrack to avoid duplicates. Simulated data stays in memory and is never saved to Health. Apple Health storage and synchronization also depend on Apple settings and policies.

PDF and CSV exports are shared only when you choose a destination using the system share sheet. Exported copies are managed separately from the original session. Delete sessions in History and clear connection events in Bluetooth Diagnostics. Local data remains until you delete it or uninstall the app; Health copies and exported files must be managed in their respective destinations. Revoke permissions in iOS Settings and Apple Health.

This website adds no advertising, analytics tools or data collection forms. This website is hosted on GitHub Pages. GitHub logs and stores visitor IP addresses for security purposes. See GitHub’s privacy statement for information about that technical data. Support is provided through GitHub issues, which are public.
